# Headers from the XLA-FFI Public API

See [xla/ffi/api](https://github.com/openxla/xla/tree/main/xla/ffi/api)
for the original files.

The XLA authors do not provide any automated or versioned way to depend
on the FFI headers, but simply instruct to copy them. See helper script
named `_get_xla_headers.sh` automating download with curl, although diffs
should be carefully inspected as the FFI API is not 100% stable yet.
