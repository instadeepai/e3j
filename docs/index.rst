e3j docs
========

Welcome to the e3j package documentation!

This library provides accelerated building blocks for Euclid-equivariant
computations, targetting JAX.
It also includes ad-hoc CUDA kernels via the `e3j_ops`
subpackage.

Please refer to `README.md <https://github.com/instadeepai/e3j>`_
for installation and compilation instructions.
